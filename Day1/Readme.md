# 🚀 Salesforce Developer Bridge Program – Day 1

## 📖 Overview
This repository contains my Day 1 learning activities from the **Salesforce Developer Bridge Program**. The focus was on understanding Salesforce fundamentals through hands-on practice, including Data Modeling, Apex Programming, SOQL, Apex Triggers, and Lightning Web Components (LWC).

---

## 🎯 Objectives
- Learn Salesforce Data Modeling concepts.
- Create Custom Objects and Relationships.
- Practice Apex programming.
- Write and execute SOQL queries.
- Build Apex Triggers using the Trigger Handler pattern.
- Create a basic Lightning Web Component (LWC).

---

## 📚 Topics Covered
- Salesforce Data Model
- Custom Objects
- Lookup & Master-Detail Relationships
- Apex Basics
- SOQL Queries
- Apex Triggers
- Trigger Handler Pattern
- Lightning Web Components (LWC)

## 💡 What I Learned
Throughout Day 1, I gained practical experience with Salesforce development. I learned how to design a simple data model using custom objects and relationships, understood the differences between Lookup and Master-Detail relationships, and practiced writing Apex code. I also explored SOQL for querying Salesforce data, implemented Apex Triggers using the Trigger Handler pattern, and built my first Lightning Web Component to display records using the `@wire` service.

---

## ⚡ Challenges Faced
- Understanding when to use Lookup vs Master-Detail relationships.
- Writing relationship-based SOQL queries.
- Debugging Apex syntax and execution errors.
- Organizing trigger logic using the Trigger Handler pattern.
- Displaying data correctly in Lightning Web Components.
- Configuring metadata and deploying components successfully.

## 🪞 Reflection
Day 1 provided a strong foundation in Salesforce development through hands-on practice. Working with custom objects, Apex, SOQL, Triggers, and LWCs helped me understand how different Salesforce components work together to build business applications. I also improved my debugging and problem-solving skills while implementing real-world scenarios. This learning experience has increased my confidence and prepared me for the more advanced Salesforce concepts that will be covered in the upcoming sessions.
