# Engineering Sprint 1 – Creating the Application Service

## Objective

Create a dedicated Apex service class responsible for handling all application-related business logic in the Placement Management System.

---

## Business Requirement

The Placement Office requires a separate service to manage application processing independently from student registration.

---

## Source Code Files

```
ApplicationService.cls
ApplicationService.cls-meta.xml
```

---

## Implementation

- Created the `ApplicationService` Apex class.
- Used a clean service-layer design.
- Kept the class focused on a single responsibility.

---

## Challenges

- Understanding the purpose of service classes.
- Separating business logic from the user interface.

---

## Reflection

A service class improves maintainability, readability, and scalability by keeping business logic organized in one place.

---

## Engineering Lesson

Keep responsibilities separate.
